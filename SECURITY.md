# Security Policy

## Supported versions

AI Server Shell has not published a stable release. Security fixes currently target the default branch.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities involving authentication bypass, cross-tenant access, credential exposure, denial of service, request smuggling, unsafe deserialization, or transport resource exhaustion.

Use GitHub private vulnerability reporting for this repository. Include:

- the affected commit or version;
- a minimal reproduction;
- expected and observed behavior;
- impact and preconditions;
- any suggested mitigation.

Please avoid accessing data that does not belong to you and avoid disruptive testing against public deployments.
